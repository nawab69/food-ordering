### PWA Setup (Frontend)

This project uses `vite-plugin-pwa` to enable installability, offline caching, and background sync.

### What was added
- Vite PWA plugin configuration with manifest and Workbox runtime caching
- Service worker registration in `apps/frontend/src/main.tsx`

### Files changed
- `apps/frontend/vite.config.ts`: Plugin added with manifest and caching rules
- `apps/frontend/src/main.tsx`: Registers `/sw.js` generated by the plugin

### Manifest
Minimal manifest is defined in Vite config:
- name: Offline Food Ordering
- theme_color: `#ef4444`
- icons: reuses `vite.svg` for dev

Replace with proper PNG icons (192/512) for production.

### Runtime caching
- `/api/menu`: Stale-While-Revalidate (cache-first feel with background revalidate)
- `/api/orders` (POST): NetworkOnly with Background Sync queue `orders-queue`

### Dev vs Build
- Dev: SW is not active by default. Build first:

```bash
pnpm -C apps/frontend build && pnpm -C apps/frontend preview
```

Then open the preview URL and check Application → Service Workers.

### Notes
- Background Sync requires HTTPS or localhost.
- For production, provide `manifest.webmanifest` icons and optionally custom `workbox` routes.
